A short poem about agency: the power to ask and to be given. An AI agent
carries the day for the person who asked — and the person is left standing
at their own front door, key in pocket, wondering which of them still has
to knock.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (UTF-8, under 280 characters).
